# ひとこと — 簡易SNS

第5回セキュリティイベント用のテキスト投稿SNSです。username / passwordによるアカウント作成、ログイン、公開・非公開投稿、本文編集、検索に対応します。現時点で意図的な脆弱性は含めていません。

## 起動

Node.js 22.22以上の22系とnpmを使用します。

```sh
cd sqli-sns
npm ci
npm start
```

[http://127.0.0.1:3000](http://127.0.0.1:3000) を開きます。設定を変更する場合は `.env.example` を `.env` にコピーして編集してください。シェルに設定済みの環境変数は `.env` より優先されます。Basic認証を使わないローカル起動では `BASIC_AUTH_USERNAME` と `BASIC_AUTH_PASSWORD` の両方を空にします。

停止は `Ctrl+C`、再起動は再度 `npm start` です。**再起動すると、全参加者の新規アカウント・投稿・編集・ログイン状態が消え、初期データに戻ります。** データファイルや初期化ボタンはありません。`npm run dev` はファイル変更でも再起動します。

## 通常操作

1. 「アカウント作成」でusernameとpasswordを登録し、ログインします。
2. 「投稿する」で本文と公開範囲を選びます。
3. 自分の投稿は詳細画面から本文を編集できます。
4. 検索では公開投稿と自分の非公開投稿を検索できます。

タイムラインは公開投稿のみ表示します。検索結果とタイムラインは新しい順に最大50件です。公開範囲は作成時に指定し、編集では本文のみ変更します。

SNS全体の保存上限は、初期データを含めて既定で投稿1,000件・アカウント100件です。共有SQLiteの容量にも8MiBの上限があり、先に達した上限で保存を拒否します。上限に達しても保存済みの内容は権限に従って閲覧できます。件数上限に達しても既存投稿の編集はできますが、容量が不足する編集は保存できません。

- username: 英小文字・数字・アンダースコア、3〜32文字。前後空白を除去し、英大文字は小文字に変換します。
- password: 8〜128文字。前後空白を含め、そのまま扱います。
- 本文: 1〜1,000文字（空白のみは不可）。検索語: 最大100文字。

起動時に次の初期アカウントと、各アカウントの公開・非公開投稿を1件ずつ用意しています。

| username | password |
| --- | --- |
| alice | alice-pass-2026 |
| bob | bob-pass-2026 |

**全利用者が1つのSQLiteデータベースを共有します。** 登録したアカウントは別ブラウザでもログインに使え、公開投稿は他の参加者にも表示されます。ユーザー名はSNS全体で一意です。非公開投稿の閲覧と投稿の編集は、その投稿の所有者としてログインした利用者だけが行えます。

ログイン状態はブラウザのセッションごとに管理します。ログアウト・Cookie削除・セッション期限切れでアカウントや投稿は削除されません。ブラウザごとのDBや50環境の枠はありません。AliceとBobはパスワードを公開した共用の教材アカウントなので、参加者ごとの操作には各自でアカウントを作成してください。

## Docker

Docker Engineを起動してから実行します。ローカル公開先は [http://127.0.0.1:3001](http://127.0.0.1:3001) です。

```sh
docker compose build
docker compose up -d
docker compose restart
docker compose down
```

単一プロセス・永続ボリュームなしの構成です。`restart` で共有DBと全セッションを初期化します。コンテナの実行検証状況は[検証記録](docs/verification.md)を参照してください。
