## 完成させるもの

意図的な脆弱性を入れない、テキスト投稿型SNSを作る。username・passwordによるアカウント作成、ログイン・ログアウト、投稿作成・本文編集、公開タイムライン、投稿詳細、公開範囲を考慮した本文検索を提供する。

初期化はサーバー再起動で行う。登録アカウント、投稿、編集結果、セッションは再起動で消え、初期データから再開する。

演習ガイド、SQL解説、初期化UI/API、脆弱版・修正版の切替は作らない。検索へのSQLインジェクション脆弱性追加は本計画の完了後の別作業とし、今回のPlan・チェックリストには含めない。

## 機能契約

### アカウントとセッション

- usernameは3〜32文字の半角英数字・アンダースコアを許可する案。前後空白を除去し、小文字へ正規化して同一環境内で一意にする。初期アカウントと重複する登録も拒否する。
- passwordは8〜128文字を許可する案。空白除去や大文字小文字の変換はしない。登録・照合で同じ規則を使い、平文をDB・ログ・エラー画面へ残さない。
- 登録後はログイン画面へ移動。ログイン成功時にセッションIDを更新し、参加者環境を維持してユーザーIDを設定する。
- ログアウトはPOSTで行い、認証状態を破棄・セッションIDを更新する。同じブラウザでの再ログインでは同じDBを使用する。
- Cookie消失やセッション有効期限切れでは新しい環境から開始し、以前の登録内容への復帰機能は設けない。

### 投稿と検索

- 本文は1〜1,000文字、空白のみは拒否する案。公開／非公開は作成時に指定し、編集できるのは本文だけ。
- `user_id` はログイン情報から設定する。更新は投稿IDとログインユーザーIDの両方で制限する。
- タイムラインは公開投稿のみ。詳細・検索は公開投稿または自分の非公開投稿に限定する。未ログインでは公開投稿のみ閲覧できる。
- 検索は本文の部分一致。検索語は最大100文字、空検索は閲覧可能な投稿一覧を返す案。`%`・`_`・エスケープ文字もリテラルとして扱う。入力をSQLへ文字列結合しない。
- 一覧・検索は投稿ID降順で最大50件の案。上限を画面に明記し、ページングは対象外とする。
- 非公開投稿への権限のない詳細・編集アクセスは404。未ログインの投稿作成・編集はログインへ誘導する。
- 投稿作成・編集・登録などの成功後はリダイレクトし、画面再読み込みで再送信しない。
- 書き込みフォームはCSRF検証を行う。username・本文・検索語はEJSでエスケープして表示する。DBエラーやスタックを応答へ出さない。

### 参加者環境と初期データ

- Alice・Bobの初期アカウントと各利用者の公開／非公開投稿をseedとして用意する。初期パスワードは公開可能な教材専用値とする。
- 初回アクセス時にサーバー側で環境を割り当て、DBを生成する。環境ID・DBパス・接続先をURLやフォームで受け付けない。
- seed作成完了後にアプリがリクエストを処理する。環境作成失敗時は中途半端なDBを登録せず、再試行可能にする。
- 環境数には設定可能な上限を設け、期限切れ環境はDB接続を閉じて解放する。上限に達した際は既存環境を消さず、新規環境への503と案内を返す。
- セッション有効期限と環境有効期限の整合を保ち、利用中の環境は解放しない。具体値は参加人数と開催時間を踏まえてPlan 4で設定する。
- 再起動後は同じCookieでも旧ログイン状態を復元しない。DBとセッションが消えるため、追加登録・投稿も消える。

## ルート案

| メソッド・パス | 用途 |
| --- | --- |
| `GET /register`, `POST /register` | アカウント作成 |
| `GET /login`, `POST /login`, `POST /logout` | ログイン・ログアウト |
| `GET /` | 公開タイムライン |
| `GET /search?q=...` | 閲覧可能な投稿の本文検索 |
| `GET /posts/new`, `POST /posts` | 投稿作成 |
| `GET /posts/:id` | 投稿詳細 |
| `GET /posts/:id/edit`, `POST /posts/:id` | 自己投稿の本文編集 |

検索は `src/posts/search.js` に集約する。現段階ではパラメーター化した通常の検索のみを実装する。

## 全体の完了条件

- 4つのPlanのコード・テスト・文書が揃い、チェックリストに実績を記録している。
- ブラウザで登録 → ログイン → 投稿 → 編集 → 検索 → ログアウトができる。
- 他人の非公開投稿・ダイジェストが漏れず、他人の投稿を編集できない。
- 別ブラウザの参加者環境へ干渉できず、再起動で全環境・認証状態が初期化される。
- 意図的な脆弱性、演習ガイド、SQL解説、初期化UI/API、版切替を追加していない。
